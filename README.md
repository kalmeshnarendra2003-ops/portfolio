# portfolio
This project is a simple Portfolio Website built using Python Flask. It displays personal information, an about section, and a contact form with a clean and simple UI.

🚀 Features

Home page with introduction

About section

Contact form

Basic HTML & CSS styling

Flask backend

🛠 Technologies

Python, Flask, HTML, CSS
